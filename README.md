# BREAK IT FOR THE CHOCOLATE

You're a creature who is hungry and need something to put inside your stomach, so you sneak inside a house. 

You start inside an old man's house, your objective is to scare the old man enough so that he gets out of the living room for you to get the chocolate waiting to be eaten.
